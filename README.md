## Что изучено

* Научился создавать массивы двумя способами: с готовыми значениями (`int[] a = { 1, 2, 3 }`) и пустыми через `new int[5]`, а также понял, что индексация начинается с нуля, а последний индекс равен `Length - 1`.

* Разобрался, когда нужен `foreach`, а когда `for`: `foreach` удобен для простого перебора значений, а `for` — когда нужен индекс или когда элементы массива нужно изменять.

* Освоил типовые алгоритмы работы с массивами: накопление суммы и среднего, поиск минимума и максимума, подсчёт элементов по условию, а также изменение элементов по индексу.
